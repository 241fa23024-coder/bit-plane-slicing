# CV Lab 5 - Bit Plane Slicing

## Aim
Perform bit-plane slicing on a grayscale image.

## Experiment
The notebook extracts the individual bit planes of an image:
- Bit plane 0
- Bit plane 1
- Bit plane 2
- Bit plane 3
- Bit plane 4
- Bit plane 5
- Bit plane 6
- Bit plane 7

## Principle
For an 8-bit grayscale image, each pixel is represented using 8 bits. Bit-plane slicing separates the image according to these individual bits.

## Output
Eight individual bit-plane images are generated and displayed.

## Requirements
Install the libraries in `requirements.txt`.

## Run
Open `Cvlab5.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab and run the cells in order.
